# English proofreading

## Pass 1: copy before layout

The supplied product name, tagline, three paragraphs, CTA, contact labels and prepared WhatsApp message were checked for grammar, spelling, punctuation and meaning. British spellings **centre**, **specialised** and **towards** are retained. The company copy has not been rewritten.

The illustrative request **I need a plan.** is a complete, natural sentence. **Done** is the final state label. **MASTER**, **AGENT** and **01–03** are labels within the conceptual illustration, not additional product features.

English text for the gallery, review controls, component sheet, motion sequence and documentation was drafted separately. Brand and product names retain their supplied spelling.

## Pass 2: text in the editable files

The complete desktop and mobile SVG files contain native text objects. Product name, tagline, each supplied paragraph, both CTA labels and URLs, contact destinations and the decoded WhatsApp message were compared with the source content. The self-contained HTML prototype was checked against the same source.

The validation result is recorded in `package-check.json`. Technical line breaks and repeated whitespace are normalised for comparison; wording and punctuation must match.

## Pass 3: exported layouts and handoff files

The actual desktop and mobile PNG exports, both opening states, component states and motion sequence were reread. Checks cover line breaks, clipping, small labels, footer contacts and both CTA instances. The desktop and mobile SVG text was also read in the browser.

The Markdown documentation, gallery labels, review controls, SVG titles, layer names and descriptions were checked again after placement. A character scan checks that the delivery documentation and viewer text contain no Cyrillic characters.

This record applies to the files included in this package. It does not certify future edits or a live product implementation.
